# 🏫 سامانه جامع مدرسه و کلاس هوشمند (نسخه مستقل بدون فیلتر — Vercel + Turso)

این پروژه نسخه **۱۰۰٪ مستقل، رایگان، بدون فیلتر در ایران و مقیاس‌پذیر برای چندین مدرسه** است که روی زیرساخت **Vercel** و دیتابیس ۵ گیگابایتی **Turso (SQLite)** اجرا می‌شود.

## متغیرهای محیطی (Environment Variables) برای هر مدرسه
برای کلاس فعلی شما مقادیر پیش‌فرض تنظیم شده‌اند و فقط کافی است `GROQ_API_KEY` را وارد کنید و دیتابیس **Turso** را از تب **Storage** متصل نمایید.

برای ارائه به **مدارس دیگر**، بدون دست زدن به کد کافی است در تنظیمات Vercel پروژه جدید این متغیرها را تعریف کنید:
- `SCHOOL_NAME`: نام مدرسه یا کلاس (مثلاً `دبیرستان علامه حلی`)
- `TEACHER_NAME`: نام معلم یا مدیر (مثلاً `استاد رضایی`)
- `TEACHER_ID`: آیدی عددی تلگرام معلم (از `@userinfobot`)
- `BOT_TOKEN`: توکن ربات تلگرام اختصاصی آن مدرسه (از `@BotFather`)
- `PANEL_PASSWORD`: رمز مدیریت پنل معلم
- `GROQ_API_KEY`: کلید رایگان هوش مصنوعی از سایت `console.groq.com`
- `TURSO_DATABASE_URL` و `TURSO_AUTH_TOKEN`: با زدن دکمه **Storage -> Turso** در Vercel به صورت خودکار ساخته و وصل می‌شوند!
